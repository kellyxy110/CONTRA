# CONTRA UX3A | The Bench

Reference-only pre-event design study. Run `npm run dev` from the repository root, then open `/`. No dependencies need installation.

The supplied 1200 x 900 JPEG is copied byte-for-byte to `design/reference/IMG_7409.jpeg`. Its SHA-256 is `1d4b982d638e86829387c87bef61d7b121f59b1e87913d4606b73142e0e15480`. The older graph reference and previous study remain unchanged remotely.

The implementation uses HTML components, CSS, a canvas radar and local fixture data. Tabs change radar/material views, search filters records, pagers change tasks/events, cards open details, and the challenge card supports a browser-session note. No wallet, model, backend or blockchain calls occur.

`comparison.html` displays the original unchanged JPEG and a 1200 x 900 implementation iframe. `capture.html` isolates that same viewport for screenshots. The source is never used as the product screen. Small avatar assets and the original mark are extracted from the supplied reference. Inter is distributed under its included SIL Open Font License; icons are Lucide (ISC).

The fixed desktop canvas preserves the owner's source composition. Narrow-screen redesign is outside UX3A. Existing graph/list and protocol requirements remain in the historical study and blueprint. This study cannot be represented as eligible hackathon implementation.

Owner visual acceptance is pending. See `design-qa.md` for measured checks and limitations.

Naming update (2026-10-28): The Bench is the current product name. The authorized title/header text substitution is the only frontend change from the approved visual baseline; layout, styling, typography, radar and assets remain frozen. The UX3C protocol milestone and pre-event implementation boundary remain unchanged.
